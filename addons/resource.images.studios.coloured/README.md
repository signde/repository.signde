### 🎨 <ins>Features</ins>

- Continual updates to reflect evolving studio branding
- Multiple internal file matches for broad compatibility
- Uniform icon sizing for consistent aspect ratio and rendering quality

---

### 📦 <ins>Installation</ins>

Once you've added the `lynxstrike.repo` source in Kodi (see the [repository README](../../README.md) for those steps):

**System > Add-ons > Install from repository** → select **lynxstrike.repo** → **Look and Feel > Image Collection** → click **Studio Icons - Coloured - Modded** to install the addon and its dependencies.

✅ Installation complete! KODI will now render any studio image that matches the **Studio Icons - Coloured - Modded** collection.
